# AL Business Analytics Dashboard

## 📊 Project Overview

The AL Business Analytics Dashboard is an interactive Tableau dashboard designed to analyze business performance and provide meaningful insights through data visualization.

## 🎯 Project Objective

* Analyze key business performance metrics
* Identify important trends and patterns
* Compare business performance across different categories
* Create an interactive and user-friendly dashboard
* Support data-driven business decisions

## 🛠️ Tools & Technologies

* Tableau
* Data Visualization
* Business Analytics
